# zfl-42 小型漆线雕工坊管理

独立静态前端应用，直接打开 `index.html` 即可使用（或 `npm run start` 后访问 http://localhost:8080）。全部数据保存在本机浏览器 localStorage，刷新不丢。

## 功能

**订单管理**
- 新建订单：关联客户、作品、交期、优先级（高/中/低），状态流转 待生产 → 制作中 → 已交付。
- 超期提示：交期已过且未交付的订单在顶部红色横幅点名提示，表格行标红并带「超期」徽标。
- 筛选：客户关键字、优先级、状态、仅看超期。

**材料库存**
- 按类别登记材料（名称、类别、单位、初始库存），类别可筛选。
- 发料：可选关联订单；库存不足时拦截并提示「库存不足：余量 X，无法发料 Y」，不产生任何变化。
- 退料：余量回补。
- 发料、退料均写入库存流水，记录时间、材料、类型、数量、余量变化（前 → 后）与关联订单。

**数据**
- 导出 JSON：一键导出作品、订单、材料、流水全量备份。
- 恢复数据：选择备份文件覆盖恢复（兼容旧版仅含作品的导出文件）。字段语义明确区分：**字段缺失 = 沿用当前数据；显式空数组 = 清空该集合**（空订单、空材料都能正确恢复）。覆盖前校验关联完整性——订单必须引用存在的作品、流水必须引用存在的材料（文件未包含的部分与当前数据合并校验）；发现失效关联、坏 JSON 或不可识别内容时整份拒绝，现有数据分毫不动。
- 已有流水记录的材料不能删除，保证库存可追溯、任何导出都可恢复。
- 作品看板：贴线中、待阴干、上金粉、待交付流转，缺陷记录，今日待阴干/缺陷/最近交付列表（原有功能保留）。

## 验收

可重复验收入口：

```bash
npm install          # 首次，安装 playwright
npx playwright install chromium   # 首次，安装浏览器
npm run acceptance
```

`acceptance.mjs` 会启动本地静态服务器并用无头 Chromium 打开页面，自动走通：新建订单 → 超期提示 → 发料（关联订单）→ 退料 → 库存不足拦截 → 筛选 → 刷新保留 → 导出 → 破坏现场后从备份恢复 → 有流水的材料删除拦截 → 恢复校验（订单引用失效作品、流水引用失效材料、坏 JSON、不可识别文件均被整份拒绝且现有数据不动）→ 字段缺失沿用当前数据、显式空数组清空订单/材料、完整备份恢复。29 项检查全部通过时退出码为 0，任一失败为非 0。

### 验收环境说明

本容器无 root 权限，Chromium 运行所需的系统库（libnss3、libgbm 等）已用 `apt-get download` 下载并解压到 `.chromium-libs/`（已加入 .gitignore），`acceptance.mjs` 启动浏览器前会自动把该目录加入 `LD_LIBRARY_PATH`。在有正常桌面/CI 环境的机器上可删除该目录，直接用 `npx playwright install --with-deps chromium` 安装依赖。
